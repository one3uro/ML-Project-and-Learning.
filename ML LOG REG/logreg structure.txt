#1. Data Splitting (Slicing the Matrix)Instead of dropping column names like a spreadsheet, you use index numbers to slice your array. You slice it into two new arrays:The Feature Array (X): This contains all your columns of clues.The Target Array (y): This is usually just the very last column containing your 0s and 1s (the answers)

.2. The Train-Test DivideYou pass your X and y arrays into a splitting tool. It randomly shuffles your rows and outputs four separate arrays:X_train (Clues for learning)X_test (Clues for the final exam)y_train (Answers for learning)y_test (Answers for the final exam)

3. Array ScalingEven with arrays, scaling is vital. If column index 0 has values around 1,000 and column index 1 has values around 0.5, the algorithm will break. You pass your X_train and X_test arrays through a scaler to compress all values into a standard range (usually between -3 and 3).

4. Training and GradingYou pass the scaled training arrays into the logistic regression model so it can learn. Then, you pass the test arrays to evaluate how well it predicts.
